Text Layer デモ

TextLayer機能

  • データ: world-capitals.geojson（世界の主要都市）、world.geojson（世界地図）
  • レイヤー: TextLayer（テキストラベル表示）
  • textPropertyによるプロパティ名指定とコールバック関数の両方に対応
  • attr/styleでフォント・配置・色などを自由に設定

実装サンプル

TextLayerの使用例

// テキストラベルの表示（プロパティ名指定）
const textLayer = new Thematika.TextLayer({
    data: capitals,
    textProperty: 'name',
    attr: {
        'fill': '#e2e8f0',
        'font-size': 11,
        'font-family': "'Roboto', 'Noto Sans JP', sans-serif",
        'text-anchor': 'start',
        'alignment-baseline': 'middle',
        'dx': 6
    }
});

// コールバック関数でテキスト内容をカスタマイズ
const textLayer2 = new Thematika.TextLayer({
    data: capitals,
    textProperty: (feature, index) => {
        const pop = feature.properties.population;
        return feature.properties.name + ' (' + (pop / 1000000).toFixed(1) + 'M)';
    },
    attr: {
        'fill': '#e2e8f0',
        'font-size': 10,
        'text-anchor': 'start',
        'dx': 6
    }
});
